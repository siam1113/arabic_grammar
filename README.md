# Arabic Grammar

A Python tool for analyzing Arabic grammar, focusing on noun (ism) inflection rules.

## What it does

The `Ism` class takes an Arabic noun and breaks it down according to different grammatical inflection patterns (for example, the tanween forms and dual/plural endings).

## Project structure

- `ism.py` — the `Ism` class that models noun inflection
- `main.py` — entry point for running the tool
- `Notes/` — written notes on Arabic grammar rules

## Purpose

This is a personal learning project for studying and modeling Arabic grammar rules in code.
